# لعبة الذكاء — THE IQ GAME

نسخة ويب جاهزة للعبة الجماعية «لعبة الذكاء»، مبنية حسب دليل التطوير المرفق.

## التصميم
تم دمج الأساليب الثلاثة معًا داخل الواجهة:
- **Claymorphism:** بطاقات كبيرة ناعمة وحواف مستديرة وطبقات ملموسة.
- **Skeuomorphism:** أزرار تبدو كأزرار فعلية مع ضغط وظلال وحواف.
- **Neumorphism:** أسطح وظلال داخلية/خارجية ناعمة للعناصر والواجهات.

## التشغيل
لا توجد مكتبات بناء أو Node مطلوبة.

### الطريقة الأسهل
افتح `index.html` مباشرة في المتصفح.

### أو عبر خادم محلي
داخل مجلد المشروع:
```bash
python -m http.server 8000
```
ثم افتح:
`http://localhost:8000`

## الملفات
- `index.html` — نقطة الدخول.
- `src/styles.css` — كل تصميم الواجهة والتفاعلات البصرية.
- `src/app.js` — منطق اللعبة، الجولات، الفرق، المؤقت، المساعدات، النقاط.
- `data/questions.js` — بنك الأسئلة 1800 سؤال جاهز للعمل محليًا.
- `data/questions.json` — نسخة JSON منظمة من البنك.
- `data/question-bank-source.txt` — المصدر الأصلي المرفق.
- `assets/logo.jpg` — الشعار المرفق.
- `README-SPEC.txt` — دليل التطوير الأصلي.

## ملاحظات
- الإجابات تُقيّم محليًا من بيانات السؤال، بدون Gemini أو أي خدمة AI.
- الخيارات العادية: 6.
- أسئلة نعم/لا: خياران فقط.
- الإجابة الصحيحة يتم خلط موضعها.
- الأخطاء لا تخصم نقاطًا مباشرة.
- المؤقت 180 ثانية.
- مساعد «حذف 4 خيارات» لا يوقف المؤقت.
- مساعدات البحث توقف مؤقت السؤال لمدة تصل إلى 60 ثانية.
- أول فريق يصل إلى 20 نقطة يفوز.
